# Changelog

## Unreleased

### Added

- **Not this** — a fourth, quiet control between Comment and Finish batch. One press sets the open file aside (`POST /api/set-aside`); on a set-aside file it reads **Bring back**. Off while setting up, and on the proposal (core's refusal is shown as written). Also in the queue's context menu (`kettle.notThis`, `kettle.bringBack`).
- Finish batch with confirmation off arms for 3 seconds and reads **Undo**; a second press cancels.
- `sync-ui-copy` carries core's `states` (`line` / `short` / `full`) into `src/uiCopy.ts` as `UI_STATES` / `uiState()`.

### Changed

- Every ritual label and hint comes from core's catalog. **Sweep** is **Finish batch** on screen; **Found Desk** is retired — the control reads **Approve** while proposing too. Command ids, settings keys and API routes are unchanged.
- Handled files are approved, sent back for rework, or set aside: all three sink to the bottom of the queue and are skipped when opening the next file. Set-aside rows are dimmed, not struck.
- Status text comes from the catalog's states: the status bar shows the connection, then the project's state while it is setting up, finishing a batch, or broken. A queue that core cannot read (409/404) marks that project broken instead of dropping the connection.
- A finished setup is announced only when core reports the project founded; otherwise the proposal stays open.
- Plain words in every extension-owned string — command titles, settings descriptions, notifications, the queue list, the chat helper and the README: project, file, summary, decision, agent, setting up. Commands with a `Kettle` category no longer repeat `Kettle:` in their title.
- `src/uiCopy.ts` regenerated from core's current catalog.

## 0.1.1 — 2026-09-12

### Added

- Six glaze-pack colour themes (Kettle Cerise, Nectar, Artichaut, Marseille, Cobalt, Graphite; dark and light each), generated by `sync-palette` from core's `static/themes/kettle-*.json`. The enamel colours chrome only; text roles keep the core accent rule.

### Changed

- `sync-palette` writes every theme in `themes/` and `package.json` `contributes.themes`; reads `resolved` shade steps and `glaze` from the core records when present; accepts `KETTLE_PALETTE` as before.
- Kettle Dark / Light regenerated from the 2026-09-11 palette (surfaces as shades of the ground; re-locked text and signals).

### Fixed

- Do not open the project QuickPick (or warn) on every window load when the open folder is not a registered Kettle desk. Auto-resolve stays silent; pick/register only when the user chooses Select Project or runs a desk command that needs a bound project. Unregistered folders leave the Desk empty-state CTA idle until asked.

## 0.1.0

### Added

- Kettle Desk panel, curated Explorer queue, editor actions, chat participant, and language-model tools for VS Code and Cursor.
- Local core discovery and auto-start with compatibility validation.
- Shared visible-copy drift check against `kettle-core`.
- Packageable VSIX, CI, contribution guidance, and security policy.

### Compatibility

- The canonical command, configuration, and Desk identity are Kettle.
- Existing `.setsweep/` Desks and a compatible legacy core identity remain readable during the migration window.
- Existing Setsweep virtual-environment locations are fallback-only.

This is a pre-release source package and is not yet published to the Visual Studio Marketplace.
